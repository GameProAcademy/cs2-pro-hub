# G6-R5.8.1 — Attestation Preflight Integrity Closure

Status: `BLOCKED_OPERATOR_CONFIGURATION`

## Scope

R5.8.1 closes two diagnostic correctness defects discovered after the R5.8 preflight implementation:

1. The canonical attestation endpoint is `https://parser.gamepro.network`. The previous diagnostic comparison against `https://gamepro.network/api/public/parser-attestation` was incorrect and could report a false mismatch.
2. The Lovable/server runtime cannot prove whether the independent GitHub Actions `RAILWAY_API_TOKEN` secret exists. The server-side diagnostic therefore reports `NOT_CHECKED` rather than inferring GitHub secret state from its own environment.

## Code changes

- `src/lib/r58Diagnostics.server.ts`

  - server-side Railway token classification is explicitly `NOT_CHECKED`.
- `src/lib/r58Diagnostics.test.ts`
  - regression tests cover canonical endpoint, obsolete endpoint, missing endpoint and non-inference of GitHub secret state.
