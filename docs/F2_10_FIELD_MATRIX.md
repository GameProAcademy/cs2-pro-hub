# F.2.10 field-by-field parity matrix

No authorized real DEM is available. Every individual data row generated by `buildNotRunFieldMatrix()` therefore remains `NOT_RUN — NO_AUTHORIZED_REAL_DEM_FIXTURE`; no synthetic value is presented as parser output.

The executable row schema is:

`category | eventOrEntity | field | pythonAvailable | wasmExportAvailable | pythonParsed | wasmParsed | pythonValueType | wasmValueType | pythonNull | wasmNull | pythonSample | wasmSample | normalizedPython | normalizedWasm | equal | status | classification | canonicalEligible | reason | evidenceRef`

The catalog expands each header, tick/player-state, combat, blind, round, bomb and grenade field into its own row. It covers map/version/playback/timing; identity/team/score; position/movement/aim; health/armor; weapons/ammo/economy; bomb/grenades/damage/deaths/blind; aggregates and game state. Discovered events outside the priority list are parsed and inventoried rather than silently dropped.

The executable parity contract retains 22 summary dimensions and supports `PASS`, `FAIL`, `NOT_RUN`, `BLOCKED`, `NOT_AVAILABLE_ON_WASM`, `NOT_AVAILABLE_ON_PYTHON`, and `PARSE_FAILED`. Field rows additionally preserve `TYPE_MISMATCH`, `VALUE_MISMATCH`, `NOT_PRESENT`, `UNAVAILABLE`, and `NORMALIZATION_REQUIRED`. Missing, null, zero, unavailable and failed values are never normalized into equality.
